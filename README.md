## Hi, I'm Alessandro

Computer Engineering student at the **University of Calabria (UniCal)**, Italy.
I work on security and AI, especially the points where each one breaks the other.

### What I'm working on

- **[Scope-rot](https://github.com/AlessandroMuleo/Scope-rot)**: a small, deterministic evaluation of one agent failure mode. When a temporary exception to a rule expires, does the LLM agent put the original rule back into force? Hypotheses, controls and a stop rule were committed before any model was run.
- **Security review of an MCP server** ([homeassistant-mcp](https://github.com/AlessandroMuleo/homeassistant-mcp)): checking whether tool annotations match what the tools actually do, e.g. a tool marked `readOnlyHint: true` that renders templates through Home Assistant's Jinja2 sandbox. Writeup in progress.
